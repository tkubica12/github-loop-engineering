The Agentic Engineering Loop

One synthetic export. One reviewed change. One bounded continuation.

Signal / 00:00

The export works.
The boundary does not.

Warning

Normal API tests pass. CodeQL identifies a caller-controlled path reaching a filesystem read.

Recorded synthetic repository: pharmacy-agentic-loop-demo.

Intent / 00:04

The issue is a contract.
Not just a prompt.

  • Export only the approved stock snapshot.
  • Reject every other filename.
  • Remain synthetic, dependency-free and compatible.

Durable context makes scope and acceptance reviewable.

Payoff preview / 00:06

The fix exists.
Follow how it earned approval.

  • Three-file diff: allowlist, literal path, regression tests.
  • The native alert no longer reproduces.
  • A person approved the exact proposal head.

Recorded merged PR #2. The next decision stays accountable.

Delegate / 00:09

Pick a worker.
Keep the contract.

  • Copilot proposes through a pull request.
  • CodeQL and tests provide external evidence.
  • OpenCode proposes a bounded source-based follow-up.

Recorded OpenCode integration: experimental imported engine, not a hosted partner agent.

Parallel work / 00:12

Three workstreams.
One control plane.

  1. Implementation
  2. Quality review
  3. Deterministic evidence

Workstreams are responsibilities, not a claim that every step is an AI agent.

Proposal / 00:15

A pull request makes
agent work inspectable.

  • Trace the proposal to its issue and actor.
  • Review a narrow diff against acceptance.
  • Inspect checks before any merge decision.

The remediation changes three files, not workflows or release authority.

Challenge / 00:22

Different checks answer
different questions.

TestsExpected behavior works.
ScopeNo dependency was added.
CodeQLUntrusted input reaches a file read.
HumanPermission to run is not merge approval.

A green build is necessary, not sufficient.

Collaborate / 00:29

Remove the authority
to choose arbitrary files.

  • Accept one allowed filename.
  • Read one literal filesystem path.
  • Test accepted and rejected requests.

Copilot proposes; a person reviews. Never deploy or probe the starter against real files.

Prove / 00:36

Probabilistic work meets
external verification.

  • Unit, API and security checks measure behavior.
  • Scope and revision identify the reviewed change.
  • The human owner retains authority.

The agent's claim of success is not the gate.

Approve / 00:40

Strong evidence makes
the decision focused.

  • Acceptance criteria map to tests.
  • Permissions and dependencies did not expand.
  • The export permits only stock.json.

The person approves the exact head. Accountability is not automated away.

Release / 00:43

Release exactly
what was reviewed.

  1. Bound package
  2. Human approval
  3. Azure OIDC
  4. Runtime evidence

Historical target: removed. Checksum is not attestation. Sandbox self-approval does not prove independent separation of duties.

Persist / 00:48

The recommendation
becomes eligible intake.

Missing regression assertion

GET /exports/%
400 {"error":"invalid export name"}

Recorded source-based maintenance predates deployment. The issue alone does not prove continuation or grant approval.

Decide / 00:51

A fresh run consumes
the prior result.

  • Run the verifier during the closing beat.
  • Original and proposal suites must pass.
  • Wrong-status and wrong-body mutations must fail.

Read the current local verifier result. It is not GitHub Actions, approval, merge, deployment, or retained recorded evidence.

Enterprise scale / 00:55

Govern the system,
not every prompt.

  • Bound access, runners, tools and networks.
  • Require evidence and named human authority.
  • Measure cost and review attention.

Rulesets, policies and capability checks turn local practice into an operating model.

The reveal / 00:58

Only one step
was coding.

GitHub preserves the work, evidence and accountable next decision.

Verified outcomes.
Accountable next decisions.
That closes the loop.
