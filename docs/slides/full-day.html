Chapter 5 / The blocking case

Evidence belongs to one revision.

  • Missing evidence blocks.
  • Evidence from another commit blocks.
  • Consistent evidence supports an accountable decision.

A green check on a different commit does not prove this change.

Chapter 5 / Capstone

Resume from evidence,
not from memory.

  1. Read

    Load prior state and verify its identity.

  2. Decide

    No-op, wait, repair, escalate or exit.

  3. Retain

    Save the result and remaining allowance.

Consistent evidence readies a decision; a named person still authorizes release.

Pilot frequent, verifiable,
reversible work.

  • Measure accepted outcomes and human attention.
  • Count failures, duplicate work and cost.
  • Keep judgment-heavy tasks supervised.

More agents are not the objective. A useful, stoppable loop is.

Every run ends with evidence
and an accountable next decision.
